# Backrooms-DOOM

Backrooms DOOM is written in extremely old C++ locked at 320x200 and uses DOOMlike rendering currently a handful of levels implemented press esc to close the program this has been hand tested on ubuntu 24.04 win11 winxp natively and winnt 3.51 on v86 below are listed the minimum requirements:
OS: NT 3.51 does not run on win9x can run on linux via Wine or APK can be ran on Android 5.0+ or iOS 12+
Processor: anything from the last 33 years or so with FPU
GPU: anything that can output 320x200
RAM: around 4-8MB will do but NT 3.51 needs 12MB
Storage: less than 10-20MB


COMMENTS: iOS as of writing this 11/25/26 does have a lot of bugs and it uses a PWA since im too broke to get the app store subscription and am not dealing with resigning every week
